Router sign-in

Pick a router, enter its login, and sign in.

Saved without encryption in this browser. Only use this on your own device.

Sign in
Opens Open without signing in

Sign in logs you in and opens the router's main screen in a new tab. If a browser blocks pop-ups, allow them for this page. If the router doesn't log in, open it with the link above and paste the password, which is copied for you.

Using a phone?
  1. Open this file in Chrome or Safari. Buttons can't open the router from inside a file preview or another app.
  2. Desktop mode isn't needed. The page goes straight to the router's own login and main screens, which skips its phone redirect.
Router won't sign in directly?
  1. Select the router and type its username and password above, then tap the button below.
  2. In Chrome, bookmark any page (⋮ then ☆), edit the bookmark, name it Router login and paste the copied text into the URL box.
  3. Tap Open without signing in above. When the router's login page shows, tap the address bar, type Router login, and pick the bookmark with the star icon.

Make one bookmark per router, with a different name each. The login is stored in the bookmark as plain text, so only do this on your own device.

Remembered logins stay in this browser only.

Edit router

Sends the login to the router's own sign-in address. The password is sent as an MD5 hash and appears in browser history.

Only helps routers that ask for the login in a browser pop-up. Some browsers show a warning, and the login can appear in your browser history, so it's off by default.
